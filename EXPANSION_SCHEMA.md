# EXPANSION SCHEMA — SchreckNET lore expansion (Writers MUST follow exactly)

Data lives in two new JS files (plain ES5, `window.*`, no imports). Do NOT touch wod_data.js
(auto-generated by scripts/gen_wod.mjs). Do NOT touch style.css or page HTML unless told.

## 1. assets/js/lore_data.js

```js
window.LORE_DB = {
  updated: "YYYY-MM-DD",
  clans: [ /* 13+ clan objects */ ],
  bloodlines: [ /* 10+ bloodline objects, same shape as clan */ ]
};
```

Each clan/bloodline object:

```js
{
  id: "nosferatu",            // lowercase, ascii, no spaces
  name: "Nosferatu",
  nickname: "Rats",           // canonical slang
  disciplines: ["Animalism", "Obfuscate", "Potence"],
  weakness: "One sentence, canonical.",
  lore_md: "3-6 paragraphs of lore: origins, antediluvian, role in the Jyhad, sect behavior.", // plain text, \n\n separators, no markdown syntax
  chars: [ /* 20 for clans, 10 for bloodlines */ ]
}
```

Each character object:

```js
{
  id: "nos001",               // clanid-prefix + 3 digits, unique in file
  name: "Known name",
  alias: "THE SEWER SAINT",   // uppercase flavor tagline
  gen: "8th",                 // generation (unknown = "desc.")
  era: "1810–1899",           // activity era
  location: { city: "Prague", place: "Underground chapel beneath Old Town" },
  threat: "high",             // low | mid | high
  lore_md: "2-4 paragraphs: history, deeds, personality, current status. Fiction allowed, canon-adjacent.",
  photo: "assets/img/char_nos001.png"
}
```

`photo` field is ALWAYS `assets/img/char_<id>.png` — do not invent other paths.
Fictional characters are fine; if using canon names keep them plausible and add `("registry attribution")` style doubt in lore_md. No real people. No trademarked franchise characters beyond generic WoD canon.

## 2. assets/js/cities_data.js

```js
window.CITIES_DB = { updated: "YYYY-MM-DD", cities: [ ... ] };
```

Each city:

```js
{
  id: "prague",               // lowercase ascii, unique
  name: "Prague",
  country: "Czechia",
  continent: "Europe",        // Europe|NorthAmerica|SouthAmerica|Asia|Africa|Oceania
  pop_m: 1.3,                 // metro population, millions
  sect: "Camarilla",          // Camarilla|Sabbat|Anarch|Independiente|Mixta|Desconocida
  prince: "Prince name or 'en disputa'",
  kindred_est: 42,            // estimated active kindred
  notes_md: "2-3 paragraphs: kindred politics, notable Elysium, sewers/tunnels of note, SchreckNET node presence." 
}
```

200+ cities: every continent, weighted to big metros. id doubles as map seed — NEVER change an id once used.

## 3. Photos / prompts

Writers ALSO emit a separate JSON array (their own file, e.g. prompts_batch_clans1.json):

```json
[ { "file": "char_nos001.png", "size": "1024x1024",
    "prompt": "Sepia dossier portrait photograph of a gaunt pale man with sunken eyes in a dark sewer corridor, 19th century attire, harsh flashlight from below, film grain, cinematic realism, no text" } ]
```

Prompt rules: NO text/letters/watermarks in image. Portrait, cinematic, era-appropriate clothing,
Nosferatu/SchreckNET mood (grain, low light). One entry per character. The orchestrator merges
batches into image_prompts.json and runs scripts/gen_images.mjs.

## 4. Maps

City underground maps are NOT images: `node scripts/gen_city_maps.mjs` generates
`assets/maps/<city_id>.svg` procedurally from CITIES_DB (deterministic per id).
Dossier pages link `assets/maps/<city_id>.svg`. Writers do nothing for maps.
